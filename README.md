# University Network Infrastructure Labs

## Overview

This repository contains a collection of networking laboratory projects completed as part of university coursework using Cisco Packet Tracer. The projects demonstrate practical knowledge of network design, IP addressing, subnetting, VLAN implementation, VLSM, routing protocols, and network troubleshooting.

The purpose of these labs is to develop hands-on experience in designing, configuring, and managing computer networks in simulated environments.

## Technologies Used

- Cisco Packet Tracer
- TCP/IP
- Routing & Switching
- VLAN
- VLSM
- OSPF
- Network Troubleshooting

## Repository Contents

### Lab Assessment
Network design and configuration exercises covering routing, switching, and connectivity verification.

### Lab Task 1 – VLAN with VLSM
- VLAN creation and configuration
- VLSM-based IP addressing
- Inter-device communication testing
- Network segmentation implementation

### Lab Task 2 – OSPF Routing
- Dynamic routing using OSPF
- Router configuration and neighbor establishment
- Route advertisement and verification
- End-to-end connectivity testing

### Lab Task 7 – Office Staff Network
- Office network topology design
- Router and switch configuration
- IP addressing and subnetting
- Connectivity verification and troubleshooting

### Office (Guest Staff)
- Guest and staff network segmentation
- Network access configuration
- Secure communication setup
- Connectivity testing
